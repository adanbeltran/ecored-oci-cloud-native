## Preparar Oracle

Se asume que la **Autonomous Database ya está creada y disponible en OCI**.

Ingrese a **Database Actions → SQL** con el usuario `ADMIN` y ejecute:

```sql
CREATE USER ecored
IDENTIFIED BY "Welcome2026!"
DEFAULT TABLESPACE DATA
TEMPORARY TABLESPACE TEMP
QUOTA UNLIMITED ON DATA
ACCOUNT UNLOCK;
```

```sql
GRANT CREATE SESSION TO ecored;
```

```sql
GRANT CREATE TABLE TO ecored;
```

```sql
GRANT CREATE SEQUENCE TO ecored;
```

```sql
BEGIN
    ORDS_ADMIN.ENABLE_SCHEMA(
        p_enabled             => TRUE,
        p_schema              => 'ECORED',
        p_url_mapping_type    => 'BASE_PATH',
        p_url_mapping_pattern => 'ecored',
        p_auto_rest_auth      => FALSE
    );

    COMMIT;
END;
```
Después, cierre la sesión de `ADMIN` y conéctese con el usuario `ecored`.

Crear la tabla de materiales:

```sql
CREATE TABLE materials (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    company_id VARCHAR2(64) NOT NULL,
    material_type VARCHAR2(120) NOT NULL,
    quantity NUMBER(18, 3) NOT NULL CHECK (quantity > 0),
    unit VARCHAR2(30) NOT NULL,
    location VARCHAR2(160) NOT NULL,
    status VARCHAR2(30) DEFAULT 'available' NOT NULL,
    published_by VARCHAR2(128) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP NOT NULL
);
```

Crear los índices:

```sql
CREATE INDEX ix_materials_company ON materials (company_id);
```

```sql
CREATE INDEX ix_materials_status ON materials (status);
```

Verificar:

```sql
SELECT * FROM materials;
```

La contraseña utilizada para `ecored` debe coincidir con `ORACLE_PASSWORD` en el archivo `.env` o `materials.docker.env`.

También puede utilizar directamente el script del repositorio:

`codigo-ecored-microservices/services/materials-service/sql/001_schema.sql`


## Etapa 1 – Ejecutar desde código en VS Code

Descargar el repositorio:

```powershell
git clone https://github.com/adanbeltran/ecored-oci-cloud-native.git
```

Ingresar al proyecto:

```powershell
cd ecored-oci-cloud-native
```

Abrir en Visual Studio Code:

```powershell
code .
```

Abra cuatro terminales en VS Code.

### Terminal 1 – Companies Service

```powershell
cd services/companies-service
```

```powershell
python -m venv .venv
```

```powershell
.venv\Scripts\Activate.ps1
```

```powershell
pip install -r requirements.txt
```

Configure el archivo `.env`.

Ejecutar:

```powershell
python manage.py runserver 127.0.0.1:8001 --noreload
```

### Terminal 2 – Materials Service

```powershell
cd services/materials-service
```

```powershell
npm ci
```

Configure el archivo `.env`.

Ejecutar:

```powershell
npm start
```

### Terminal 3 – API Gateway

```powershell
cd local-gateway
```

```powershell
npm ci
```

Configure el archivo `.env`, incluyendo Firebase y las rutas:

```text
COMPANIES_URL=http://127.0.0.1:8001
```

```text
MATERIALS_URL=http://127.0.0.1:8002
```

Ejecutar:

```powershell
npm start
```

### Terminal 4 – Frontend

```powershell
cd frontend
```

```powershell
npm ci
```

Configure el archivo `.env`, incluyendo Firebase y:

```text
VITE_API_URL=http://127.0.0.1:8080/api
```

Ejecutar:

```powershell
npm run dev
```

Abrir:

```text
http://localhost:5173
```

## Etapa 2 – Ejecutar desde imágenes Docker

Se asume que se encuentra ubicado en la carpeta `docker.env` y que ya están configurados:

```text
companies.docker.env
materials.docker.env
gateway.docker.env
frontend.docker.env
```

Descargar Companies:

```powershell
docker pull adanbeltran/ecored-companies:1.0
```

Descargar Materials:

```powershell
docker pull adanbeltran/ecored-materials:1.0
```

Descargar API Gateway:

```powershell
docker pull adanbeltran/ecored-local-gateway:1.0
```

Descargar Frontend:

```powershell
docker pull adanbeltran/ecored-frontend:1.0
```

Verificar las imágenes:

```powershell
docker images
```

Crear la red:

```powershell
docker network create ecored-net
```

Ejecutar Companies:

```powershell
docker run -d --name ecored-companies --network ecored-net --env-file companies.docker.env -p 8001:8001 adanbeltran/ecored-companies:1.0
```

Ejecutar Materials:

```powershell
docker run -d --name ecored-materials --network ecored-net --env-file materials.docker.env -p 8002:8002 adanbeltran/ecored-materials:1.0
```

Ejecutar API Gateway:

```powershell
docker run -d --name ecored-local-gateway --network ecored-net --env-file gateway.docker.env -p 8080:8080 adanbeltran/ecored-local-gateway:1.0
```

Ejecutar Frontend:

```powershell
docker run -d --name ecored-frontend --network ecored-net --env-file frontend.docker.env -p 8088:80 adanbeltran/ecored-frontend:1.0
```

Verificar:

```powershell
docker ps
```

Abrir:

```text
http://localhost:8088
```

Consultar logs si es necesario:

```powershell
docker logs ecored-companies
```

```powershell
docker logs ecored-materials
```

```powershell
docker logs ecored-local-gateway
```

```powershell
docker logs ecored-frontend
```

## Pruebas

Utilice:

```text
tests/ecored-end-to-end.http
```

Realice las pruebas principales:

1. Verificar el endpoint `/health` del API Gateway.
2. Verificar que una solicitud protegida sin token sea rechazada.
3. Iniciar sesión mediante Firebase.
4. Crear y consultar una empresa.
5. Crear y consultar un material.
6. Comprobar el flujo completo:

```text
Frontend
   ↓
API Gateway
   ↓
Microservicios
   ↓
Bases de datos
```

En la **Etapa 1**, los servicios se comunican utilizando `127.0.0.1`.

En la **Etapa 2**, los contenedores se comunican mediante sus nombres dentro de la red Docker:

```text
http://ecored-companies:8001
```

```text
http://ecored-materials:8002
```

Para configuraciones adicionales, explicación de las variables de entorno y solución de errores, consulte el [Taller 5 completo](https://github.com/adanbeltran/ecored-oci-cloud-native/blob/main/talleres-ecored-cloud-native/taller05/05-Taller-CreacionMicroservicios-ApiGateway.md).
